# 📅 Attendance Calculator

A smart and responsive web application designed for students to easily calculate, track, and manage their academic attendance requirements. 

---

## 🚀 Features

- **Flexible Input Modes:** Enter your current attendance either as a direct percentage or by specifying attended versus total classes.
- **Target Tracking:** Set your required minimum attendance percentage (e.g., 75%).
- **Real-Time Calculations:** Computes exactly how many classes you need to attend (or can afford to skip) to meet your target.
- **Dark/Light Mode:** Includes a built-in theme toggle for a comfortable user experience day or night.
- **Responsive UI:** Clean, modern interface that looks great on both mobile and desktop screens.

---


## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure
- **CSS3:** Custom styling, layout design, and theme support
- **JavaScript:** Core logic for attendance computation and DOM manipulation
